
# 🐬 ClickerGameTS Desktop Edition

**ClickerGameTS Desktop Edition** is a Windows desktop adaptation of ClickerGameTS, built using Electron and Node.js.

It brings the ClickerGameTS experience into a standalone desktop application while keeping the original web edition completely independent.

- 🌐 Online service integration
- 📦 Windows installer

## 🌐 Internet Connectivity

ClickerGameTS Desktop Edition supports offline gameplay.

However, some features depend on remote services and may be limited or unavailable without an internet connection.

### Available Offline
- Clicking
- Farming
- Locally available gameplay features
- Local save functionality

### Internet Required
- Beta Program
- Online account-related features
- Changelog updates
- Features that communicate with remote services

An internet connection is recommended for the complete experience.

# Clone this software


## Requirements
- Git
- Windows 11/10 machine

1. To clone this repo open your terminal and type
```bash
git clone https://gitlab.com/AleemHassa-1/gitlab-isthebest.git ClickerGameTS
```
2. Done, now you have the source code on directory "ClickerGameTS"
